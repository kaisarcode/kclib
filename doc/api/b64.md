# b64 scripting API

Base64 encoding and strict RFC 4648 decoding.

## Lua

```lua
local encoded = b64.encode(data)
local decoded = b64.decode(encoded)
local version = b64.version()
```

`encode(data)` accepts binary data and returns a Base64 string. `decode(text)` returns decoded binary data and fails for malformed or non-canonical Base64. Empty input is valid.

## JavaScript

```js
const encoded = await b64.encode(data);
const decoded = await b64.decode(encoded);
const version = await b64.version();
```

Binary input and decoded output are `Uint8Array` values. Allocation cleanup is internal.
